# Tools Documentation

This directory documents every developer-facing tool integrated into this project.
Each subdirectory contains a focused guide for one tool.

| Folder    | Tool            | Purpose                                             |
|-----------|-----------------|-----------------------------------------------------|
| `cicd/`   | GitHub Actions  | Automated CI/CD pipeline & EAS build triggers       |
| `git/`    | Git / Commitlint| Commit conventions & semantic-release workflow       |
| `husky/`  | Husky           | Local Git hooks (pre-commit lint, commit-msg lint)  |
| `maestro/`| Maestro         | Mobile E2E / smoke testing                          |
| `sentry/` | Sentry          | Crash reporting & performance monitoring            |
